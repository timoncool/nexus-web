This is the UI half of **[Nexus Fast](https://github.com/timoncool/nexus-service)**, a fork of [Nexus](https://github.com/hello-nexus/nexus). The description, the full list of changes, the numbers, downloads and install steps live in the service repo: **[timoncool/nexus-service](https://github.com/timoncool/nexus-service)** ([по-русски](https://github.com/timoncool/nexus-service/blob/lighting-accent/README_RU.md)).

Это интерфейс **[Nexus Fast](https://github.com/timoncool/nexus-service)** — форка [Nexus](https://github.com/hello-nexus/nexus). Описание, список изменений, цифры, загрузка и установка — в репозитории службы: **[timoncool/nexus-service](https://github.com/timoncool/nexus-service/blob/lighting-accent/README_RU.md)**.

Branch `share-lighting-accent`. Build for the service: `npm install`, then `npm run build:service`. The original build notes are in [docs/UPSTREAM_README.md](docs/UPSTREAM_README.md).
